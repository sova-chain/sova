# sova.io

The Sova website: a vision landing page at `/` (Sova is the EVM that can see
Zcash), the whitepaper at `/paper` (`src/components/Paper.astro`, also at
`/v/paper`), and plain pages beside them: `/why`, `/build`, `/sips`, `/mine`,
`/node`, `/story`, `/ashwings` and `/press`. It's built with
[Astro](https://astro.build) as a fully static site. The paper uses two small
vanilla scripts (figure motion and the table of contents' active-section
highlight); the landing page's terminal is CSS-only, and its one inline line of
script forwards old paper links (`/#s4`) to `/paper#s4`; the other pages use no
script. Pre-release.

## Commands

Requires Node 22.12 or newer (Astro 7's floor; see `.nvmrc`).

```bash
cd site
npm ci            # install exactly what package-lock.json pins
npm run dev       # dev server with hot reload, http://localhost:4321
npm run build     # static build into site/dist/
npm run preview   # serve site/dist/ locally to check the real build
```

Astro's anonymous telemetry is switched off in every script
(`ASTRO_TELEMETRY_DISABLED=1`), so building doesn't contact anything.
