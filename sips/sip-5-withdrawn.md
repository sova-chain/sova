# SIP-5: withdrawn

- Status: **Withdrawn** (2026-09-23).

SIP-5 was reserved for wrapped ZEC. Wrapped ZEC is not a protocol rule
that every Sova node runs: it is a custodial product, operated by Sova
Labs as **wZcash** at wz.cash, and the network makes no guarantees about
it. Its design lives in `docs/design/wz-cash.md`. The number is not reused.
